# Contributing to DevFortress

Thank you for your interest in DevFortress.

## Current Policy: Contributions Not Accepted

We are not accepting pull requests or external code contributions at this time.

The SDK is closed-source and distributed exclusively via npm —
there is no SDK source code in this repository to contribute to.

The open platform layer in this repository is maintained solely by the core
team and is directly tied to active patent applications
(KIPI KE/P/2026/005970–005973). Accepting third-party contributions during
this period introduces legal complexity around inventorship and code ownership
that we cannot responsibly manage.

## How You Can Help

- **Bug reports:** Open a [GitHub Issue](../../issues) with steps to reproduce
- **Feature requests:** Open a [GitHub Issue](../../issues) tagged `enhancement`
- **Security disclosures:** Email security@devfortress.net — do not open
  public issues for vulnerabilities

## This Policy Will Change

We intend to open contributions once the patent process matures and we have
the capacity to review PRs responsibly. Watch this repo for updates.
